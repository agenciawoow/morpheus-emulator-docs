# Account and security

Your personal settings live in two pages, both reachable from the **account menu** (your e-mail in the top-right corner):

- **Edit profile** – e-mail, phone, password and two-factor authentication.
- **Morpheus Sender** – which notifications you receive and where.

## Editing your profile

Open **account menu → Edit profile**. The **Your account** card shows your account details.

| Field | Description |
|---|---|
| **Username or e-mail** | The login you use to sign in. |
| **Phone (optional)** | Used for WhatsApp notifications. Choose the country code first; the input mask adjusts automatically. |

Click **Save**. You will see **Profile updated.**

### Changing your password

The **Change password** section is optional. Leave it blank to keep your current password. If you fill it in, all three fields are required:

1. **Current password** – your existing password.
2. **New password** – at least 8 characters.
3. **Confirm new password** – type the new password again.
4. Click **Save**.

| Message | Fix |
|---|---|
| **Enter your current password.** | Fill in **Current password**. |
| **Current password is incorrect.** | Re-type your current password. |
| **The new password must have at least 8 characters.** | Choose a longer password. |
| **The new password and its confirmation don't match.** | Type the same value in both fields. |

{% hint style="success" %}
Use a unique password that you don't use anywhere else, ideally generated by a password manager.
{% endhint %}

## Two-factor authentication

Two-factor authentication (2FA) adds a 6-digit code from an authenticator app to every login. It protects your server even if your password leaks. Compatible apps include Google Authenticator, Authy, 1Password and Microsoft Authenticator.

The **Two-factor authentication** card is on the **Edit profile** page.

### Enabling 2FA

1. Click **Enable**.
2. **Scan the QR code in your authenticator app.** If you can't scan, use **Or paste this key manually into the app:** and copy the key shown (settings: SHA-1 algorithm · 6 digits · 30s period).
3. **Type the 6-digit code to confirm:** enter the code your app now shows.
4. Confirm. You will see **2FA enabled. Next time you sign in, the panel will ask for the code.**

The card now shows the **active** badge.

### Disabling 2FA

1. Click **Disable**.
2. Type a current code from your authenticator (this prevents someone who stole your session from turning 2FA off).
3. Confirm. You will see **2FA disabled. You can turn it back on at any time.**

{% hint style="warning" %}
If you lose access to your authenticator app, ask support to **reset 2FA** for your account. You can then enable it again with a new phone.
{% endhint %}

{% hint style="info" %}
If you see **2FA is globally disabled by the admin.**, two-factor authentication has been turned off for the whole platform and the option is temporarily unavailable.
{% endhint %}

## Notification preferences (Morpheus Sender)

**Morpheus Sender** decides which kinds of notification you receive. Open it from the sidebar (**Morpheus Sender**) or from the account menu.

Alerts always arrive in the panel (the bell in the top bar). If your account is **Premium**, they are also delivered to your registered WhatsApp number.

### Notification types

| Type | What it covers | Recommendation |
|---|---|---|
| **Urgent** | Critical incidents: server offline, ban, credential leak. | Keep it always on. |
| **Server status** | Operational alerts: GameServer went down, MuServer restarted, the connection to your machine was lost. | On by default. |
| **Updates** | New versions and configuration changes that affect your server. | On. |
| **News and announcements** | Panel feature releases, community events and announcements. | Optional. |

Tick the types you want and click **Save preferences**. You will see **Preferences saved.**

### Premium status box

At the top of the page a box tells you how notifications will be delivered:

| Box | Meaning |
|---|---|
| **Premium active** | Checked notification types arrive in the panel **and** on your registered WhatsApp. |
| **Premium active — no phone** | You only receive notifications inside the panel. Click **Add a phone number** to fill in your phone in your profile. |
| **Premium inactive** | Your account is not Premium, so you don't receive automatic notifications outside the panel. Contact support to enable it. |

{% hint style="info" %}
Phone numbers must contain digits only, including the country code (for example `5511999999999`). The profile form formats it for you.
{% endhint %}

## Changing the server logo

You can personalise the avatar shown in the sidebar:

1. Click the round avatar at the top of the sidebar (a wrench icon appears on hover, tooltip **Change server logo**).
2. In **Server logo**, choose a file: PNG, JPEG, WebP or SVG, up to 256 KiB.
3. To go back to the default gradient avatar, use **remove** and confirm **Remove logo?**.

## Security checklist

- Enable 2FA on every account that can edit files or control services.
- Review [Logs and audit](logs-and-audit.md) regularly to see who changed what.
