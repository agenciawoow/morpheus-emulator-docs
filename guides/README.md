# Guides

The rest of this documentation explains **how each system works**. These guides explain **how to use them together** to build a server that players enjoy, come back to, and support financially over the long term.

They are opinionated, practical playbooks. Every feature they mention links to its reference page, so you can go from a strategy straight to the setting that implements it.

## Available guides

| Guide | Read it when you want to |
|---|---|
| [Profitable server methodology](profitable-server-methodology.md) | Plan the whole life of your server: positioning, launch, acquisition, retention, monetization, economy health, operations and the numbers to watch. |
| [Multi-platform playbook](multiplatform-playbook.md) | Get the most out of each platform (Windows, Android, iPhone and iPad, macOS, web browser and mobile browser) and promote each one to the right audience. |
| [Monetization catalog blueprint](monetization-catalog.md) | Build a fair, ready-to-adapt store: product categories, illustrative price ladders, bundles, limited-time offers, what not to sell, and where to set each item up in the panel. |

## Suggested reading order

{% stepper %}
{% step %}
### Start with the methodology

Read the [Profitable server methodology](profitable-server-methodology.md) end to end once. It gives you the phases and the vocabulary the other two guides use.
{% endstep %}

{% step %}
### Pick your platform focus

Use the [Multi-platform playbook](multiplatform-playbook.md) to decide which platforms you will promote first, based on the audience you chose.
{% endstep %}

{% step %}
### Design the store last

Build your catalog with the [Monetization catalog blueprint](monetization-catalog.md) only after positioning and economy are decided. A store designed before the economy almost always ends up selling power.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
All numbers in these guides (prices, rates, percentages, targets) are **illustrative examples** to show the reasoning. They are not promises of results, and every community is different. Test, measure and adjust for your own players.
{% endhint %}
